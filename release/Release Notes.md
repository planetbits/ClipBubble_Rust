### Features
- **Floating Clipboard Bubbles** - Clipboard items appear as semi-transparent, floating bubbles on screen
- **Organic Drift Animation** - Bubbles glide across the screen using non-linear sine/cosine wave paths
- **Hardware-Accelerated Animations** - Smooth spawn (bounce-in) and death (dissipate) animations with GPU acceleration
- **Smart Auto-Paste** - Click a bubble to copy content to clipboard and automatically paste into active application
- **Hover Interaction** - Bubbles become fully opaque and stationary on mouse hover for easy clicking
- **Magnetic Mouse Effects** - Bubbles gently attract or repel when mouse pointer is within 100px radius
- **System Tray Integration** - Access configuration menu via system tray icon
- **Focus-Avoidance** - Windows use WS_EX_TRANSPARENT and WS_EX_NOACTIVATE flags to never steal focus
- **Windows 11 Fluent Design** - Modern UI with blur backdrop-filter and smooth opacity transitions
- **Low Resource Usage** - Ultra-low RAM usage (<12MB idle) with near-zero CPU overhead
